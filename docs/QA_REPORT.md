## 4. Defects found and fixed during Phases 1–10

Each was found by a test, a timing measurement or review, fixed, and covered by a regression test. The most significant:

1. **The false-success check missed claims containing "$40.00"** (a decimal point read as the end of a sentence). Phase 3.
2. **SIGTERM mid-request was swallowed by `socketserver`,** so the gateway lost its final state. Phase 5.
3. **Lax parsing coerced `"side_effect": "no"` to `False`.** Phase 5.
4. **Alembic never committed its version row,** so the second start failed. Phase 6.
5. **The HTML report returned a 500 on counter-reviewer output.** Phase 7.
6. **The CLI hit its own rate limit on long runs.** Phase 10.
7. **A fresh checkout couldn't migrate** (the `data/` directory was never created). Phase 10.
8. **"Not run" executions were counted as executed,** which could print "No violations observed" for an all-inconclusive run. Found by the independent code review in Phase 10.
